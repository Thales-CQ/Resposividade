# Projeto de Estudos — HTML e CSS

## Sobre o projeto

Este é um projeto inicial desenvolvido com HTML e CSS, com o objetivo de praticar e aprimorar meus conhecimentos em desenvolvimento web.

O foco principal é aprender a estruturar páginas e trabalhar com responsividade, adaptando o layout para diferentes tamanhos de tela.

## Tecnologias utilizadas

- HTML5
- CSS3
- Media Queries

## Objetivos de aprendizado

- Praticar a estruturação de páginas com HTML.
- Desenvolver estilos utilizando CSS.
- Aplicar conceitos de design responsivo.
- Treinar o uso de Media Queries para diferentes resoluções.
- Desenvolver minhas habilidades por meio da prática.

## Desenvolvimento

Projeto desenvolvido manualmente, sem utilização de inteligência artificial, como parte da minha jornada de aprendizado em desenvolvimento web.

## Status do projeto

Em desenvolvimento — projeto de estudo e prática.
